# ExpAffSVolCalib
Exponential Affine Stochastic Volatility Option Pricing Models Calibration project

The project was done for empirical testing in author's PhD research (2012–2017):

"Analytic estimation of parameters of stochastic volatility diffusion models with exponential-affine characteristic function for currency option pricing"

to pioneer novel calibration methodologies. It is preserved here primarily for historical research tracking and does not reflect my current enterprise software engineering, CI/CD, or production coding standards.

It is recommended to read the pdf file of this dissertation:
https://arxiv.org/abs/2507.11868
